# CharacterApp — лист персонажа Espires Games

Настольное приложение для ведения листов персонажей в самописной d20-системе.
Windows, WPF, .NET 8. Одно окно вместо стопки бумажек, ластика и калькулятора.

> Система не совпадает с D&D 5e: здесь есть сверх-хиты, аура, слух, зрение,
> треугольник развития Тело/Разум/Дух и владения с рейтингом 0–3.

---

## Что умеет

| Раздел | Что там |
|---|---|
| **Главная** | Имя, класс, хиты, броня, уклонение, инициатива, мана, стамина, портрет, треугольник развития |
| **Предыстория** | Раса, мировоззрение, внешность, возраст, уровень, опыт, стартовые бонусы |
| **Снаряжение** | 15 слотов экипировки с картинками, перетаскивание предметов между слотами |
| **Инвентарь** | Предметы с редкостью, количеством, описанием и картинкой; золото/серебро/медь |
| **Характеристики** | Шесть атрибутов, спасброски, 22 навыка с тренировкой и владением |
| **Активные / пассивные навыки** | Списки с категориями и описаниями |
| **Владения** | Черты 4/9/18 уровня, черты гуманоидов (до 5), владения и языки с рейтингом |
| **Атаки** | Список атак с описанием |
| **Журнал сессий** | Записи по играм |
| **Ресурсы** | Трекер HP и произвольных ресурсов с цветовой маркировкой |
| **Кубики** | d4–d100, преимущество/помеха (в том числе для формул — видно оба броска), формулы вида `3d6+2`, история бросков |
| **Свои листы** | Пользовательские таблицы с произвольными колонками |

Плюс: несколько персонажей в табах, светлая и тёмная темы, настраиваемый
акцентный цвет, покраска отдельных полей, экспорт в PDF, поиск по страницам,
автосохранение, проверка обновлений через GitHub Releases.

## Установка

Скачай `CharacterApp.exe` из [релизов](https://github.com/Fanarier/CharacterApp/releases)
и запусти. Устанавливать .NET отдельно не нужно — он встроен в exe.

Windows SmartScreen может ругнуться на неподписанный файл:
«Подробнее» → «Выполнить в любом случае».

## Где лежат файлы

**Персонажи** — обычные `.json`, сохраняются куда скажешь (`Ctrl+S`).

Портрет и картинки предметов лежат **внутри самого файла**, поэтому персонажа
достаточно передать одним файлом — ничего прикладывать не нужно. Из-за этого
файл весит больше обычного текста: примерно на треть больше суммарного размера
картинок.

Файлы, сохранённые старыми версиями, открываются как раньше: если рядом лежит
папка `<имя файла>_assets`, картинки подхватятся из неё и при следующем
сохранении переедут внутрь файла.

**Настройки и служебные файлы** — в `%AppData%\CharacterApp\`:

| Файл | Что внутри |
|---|---|
| `config.json` | Все настройки: тема, язык, шрифт, акцентный цвет, автосохранение, кастомные листы |
| `session.json` | Открытые табы персонажей — восстанавливаются при следующем запуске |
| `log.txt` | Лог ошибок. **Если что-то сломалось — присылай этот файл** |
| `*.bad` | Повреждённые версии файлов выше, отложенные на всякий случай |

Быстро попасть в папку: `Win+R` → `%AppData%\CharacterApp` → Enter.

## Автосохранение

Включается в Настройках: папка, интервал в минутах и шаблон имени.
Хранятся последние 5 снимков, старые удаляются.

Шаблон **обязан** содержать собственный префикс до подстановки даты —
`autosave_{0:yyyyMMdd_HHmmss}.json`. Если оставить только дату
(`{0:yyyyMMdd}.json`), приложение не сможет отличить свои снимки от чужих
файлов и на всякий случай откажется чистить папку вообще.

Автосохранение не заменяет `Ctrl+S`: снимки пишутся в отдельную папку,
а не в твой файл персонажа.

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и Windows
(WPF на Linux/macOS не собирается).

```powershell
git clone https://github.com/Fanarier/CharacterApp.git
cd CharacterApp
dotnet build CharacterApp/CharacterApp.csproj -c Debug
```

Сборка релизного exe и выкладка на GitHub — см. [RELEASE.txt](RELEASE.txt).

Версия задаётся в одном месте — `<Version>` в `CharacterApp/CharacterApp.csproj`.
Её нужно бампать вместе с git-тегом (`<Version>1.1.0</Version>` ↔ тег `v1.1.0`),
иначе проверка обновлений будет предлагать один и тот же релиз бесконечно.

## Структура проекта

```
CharacterApp/
├── Models/            Character, EquipmentItem, InventoryItem — то, что уходит в JSON
├── Pages/             Страницы приложения, по одной на раздел
├── Controls/          Переиспользуемые контролы (слот экипировки, рейтинг, кубики)
├── Dialogs/           Модалки: подтверждение, редактор предмета
├── Helpers/           PdfExporter, логгер, перенос картинок, уведомления
├── Themes/            DarkTheme.xaml / LightTheme.xaml
├── Strings/           Локализация (ru полная; en и jp частичные)
└── Resources/         Общие стили
```

Зависимости: `Newtonsoft.Json` (персонажи), `QuestPDF` (экспорт), `Octokit`
(проверка обновлений).

## Известные ограничения

- Английская и японская локализации покрывают меньшую часть интерфейса —
  большинство надписей пока зашиты в XAML по-русски.
- Экспорт в PDF односторонний: обратно PDF не читается.
- Приложение только под Windows.
